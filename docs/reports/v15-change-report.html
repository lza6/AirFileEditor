4. 架构决策

决策方案理由
TaskController 定位domain 层接口 + core 层实现保持依赖方向 :app → :data → :domain ← :core，不破坏 Clean Architecture
ReplaceProgressManager 保留标记 @Deprecated 不删除ReplaceProgressManagerTest 11 个用例仍有效，保留向后兼容
SnackbarManager 架构SharedFlow 事件总线异步非阻塞，与 Compose 协程生命周期自然集成
ProgressTracker 时钟构造函数注入 clock 函数避免 mockkStatic(System) 无限递归，同时保留测试可预测性
Windows 文件锁移除 doFirst 清理，改为 try-catch doLastGradle 测试执行器与 doFirst 并存开发锁冲突，删掉后各司其职
